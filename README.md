# Dotfiles

我的Arch Linux + Hyprland配置文件

## 环境
- OS: Arch Linux
- WM: Hyprland
- Terminal: Kitty
- Shell: Zsh
- Bar: Waybar

## 前置条件
- 已配置archlinuxcn源
- 建议提前把shell换为zsh

## 安装
```
git clone https://github.com/peter20230221-wq/dotfiles ~/.dotfiles &&
cd ~/.dotfiles &&
bash install.sh 
```
